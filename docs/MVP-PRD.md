# 金融情报站 MVP · 产品需求文档

> 版本：V0.1 · 2026-06-04 · 主人：老吴（丰辰）

## 一、产品定位
**自用型跨市场（美股+A股+港股）金融情报站**，聚焦"前瞻赛道发现 + 个股可投性分析"。

## 二、MVP 核心功能（V1 必须有）

### 1. 首页 / 赛道看板
- 展示 **Top 10 赛道**（按热度评分排序）
- 每个赛道卡片显示：
  - 赛道名（如：AI 算力 / 创新药 / 储能）
  - 热度评分（0-100）
  - 横跨的三地市场图标
  - 包含的标的数量
  - **三色标签分布**（🟢长期 / 🟡中期 / 🔴短期）

### 2. 赛道详情页
- 赛道名 + 一句话描述 + 时间线（最近 7 天关键事件）
- 标的池卡片：每只股票显示
  - 代码 + 名称 + 所属市场
  - 当前价 + 涨跌幅
  - **三色标签**（可视化色块）
  - 一句话投资逻辑

### 3. 标的详情页
- 基础信息（代码、市场、行业、当前价）
- **三色标签 + 触发原因**
- 投资逻辑（结构化卡片）：
  - 🟢 长期价值：业绩、分红、护城河
  - 🟡 中期趋势：产业拐点、产能周期
  - 🔴 短期事件：财报、催化、消息
- 风险点
- 数据源链接

### 4. 反馈机制（轻量）
- 每个标的页面底部 4 个按钮：👍 / 👎 / 已买入 / 已卖出
- 点击后记录到本地数据库，反哺评分模型

## 三、MVP 不做（明确排除）

- ❌ 用户系统 / 登录注册
- ❌ 实时报价（T+1 即可）
- ❌ 复杂图表（K线、技术指标）
- ❌ 付费墙
- ❌ 移动端 App（响应式网页即可）
- ❌ 多语言（只做中文）
- ❌ 复杂回测系统

## 四、技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 前端 | Next.js 14 + TailwindCSS | 部署 Vercel 零配置 |
| 数据 | 静态 JSON（先用）→ 后接 API | MVP 阶段先 mock |
| 部署 | Vercel 免费版 | 主人选择 |
| 数据源 | 东方财富 / 新浪财经 / Yahoo Finance / SEC EDGAR | 全免费 |
| 数据采集 | Python 脚本 + cron | 复用已有技术栈 |

## 五、三色标签系统（核心创新）

| 标签 | 含义 | 触发特征 | 持有周期 |
|------|------|---------|---------|
| 🟢 长期价值 (V) | 业绩稳健、护城河深 | ROE>15%、PE 合理、稳定分红 | 3年+ |
| 🟡 中期趋势 (T) | 产业拐点、产能周期 | 行业景气度上升、订单增长 | 6-12月 |
| 🔴 短期事件 (E) | 消息面、催化剂 | 财报、发布会、政策、并购 | <3月 |

**一只股票可以同时有多个标签**（如：英伟达 = 🟢+🟡）。

## 七、验收标准

✅ V1 上线时，老吴打开网页能：
1. 看到 10 个赛道 + 每赛道 3-5 只股票
2. 点开任意赛道，看到结构化标的列表
3. 点开任意股票，看到三色标签 + 投资逻辑
4. 点击反馈按钮有反应
5. 在手机和电脑都能正常浏览
